Authentication

The contract separates health probes from token-backed business operations.

Bearer token Partner business endpoints under /api/v1 expect a Bearer token unless the operation is the OAuth token issue flow.
Client credentials /api/v1/oauth/token/{tenant_slug} issues access tokens and supports client credentials exchange.
Idempotency required Every mutating operation includes the Idempotency-Key header in the OpenAPI contract.
